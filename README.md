# cristina granillo 
tengo 17 años y actualmente estudio el segundo año de la especialidad en Desarrollo de Software en el Instituto Nacional "Ernesto Flores".

Elegí esta carrera porque siempre me dio curiosidad entender la lógica detrás de las aplicaciones que usamos a diario, cómo se construyen los sitios web y de qué manera la tecnología resuelve problemas cotidianos.

A lo largo de este tiempo he adquirido conocimientos prácticos utilizando herramientas y lenguajes como HTML, CSS, JavaScript, PSeInt, Scratch, GIMP y StarUML para el modelado de sistemas.

De todo lo que he trabajado, lo que más me apasiona es el desarrollo web con HTML, CSS y la interactividad que se logra al programar, ya que resulta gratificante ver cómo una idea en código cobra vida en la pantalla. Me motiva seguir explorando nuevas tecnologías, frameworks y herramientas que me permitan construir proyectos más completos.

Reconozco que la programación presenta retos constantes y que aún me queda un camino largo por recorrer, pero mantengo la disciplina para seguir practicando y superando cada reto. Para mí, estudiar Desarrollo de Software representa la oportunidad de desarrollar mi potencial, perfeccionar mis habilidades técnicas y construir una base sólida para mi futuro académico y profesional.
